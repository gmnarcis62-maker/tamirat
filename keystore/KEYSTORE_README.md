# کیستور امضای انتشار (Release Keystore)

یک کیستور واقعی برای امضای نسخه‌ی release برنامه، همراه با رمزهای تصادفی و قوی، در این پوشه ساخته شده:

- `tamirkar-release.jks` — فایل کیستور
- `keystore.properties` — رمزها و مشخصات (alias: `tamirkar`)

Gradle به‌صورت خودکار این کیستور را برای build نوع **release** استفاده می‌کند (تنظیمات در `app/build.gradle.kts`).

## ⚠️ نکات امنیتی حیاتی

1. **این فایل‌ها را در Git عمومی (GitHub/GitLab عمومی) قرار ندهید.** در `.gitignore` پروژه از قبل این مسیرها نادیده گرفته شده‌اند.
2. **این کیستور را جایی امن نگه دارید** (مثلاً یک پسوورد منیجر یا فضای ابری خصوصی). اگر این فایل را گم کنید، **دیگر هرگز نمی‌توانید نسخه‌ی جدیدی از برنامه را با همان امضا منتشر کنید** و کاربران مجبور خواهند شد اپ را کامل حذف و دوباره نصب کنند.
3. از آنجا که این کیستور در یک محیط خودکار (بدون تعامل انسانی) ساخته شده، **اگر امنیت این فایل زیر سؤال است یا مشکوک هستید که کس دیگری هم آن را دیده، آن را دور بریزید و یک کیستور جدید بسازید** (دستور زیر) پیش از اولین انتشار واقعی در مایکت.

## ساخت یک کیستور جدید (در صورت نیاز)

```bash
keytool -genkeypair -v \
  -keystore keystore/tamirkar-release.jks \
  -alias tamirkar \
  -keyalg RSA -keysize 2048 -validity 9125
```

سپس مقادیر جدید را در `keystore/keystore.properties` جایگزین کنید.

## Build خروجی امضاشده

```bash
./gradlew bundleRelease   # برای Android App Bundle (.aab) — فرمت پیشنهادی مایکت
./gradlew assembleRelease # برای APK مستقیم
```

خروجی در مسیر `app/build/outputs/` قرار می‌گیرد.
